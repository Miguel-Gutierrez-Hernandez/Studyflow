1. Redes Neuronales

Las Redes Neuronales Recurrentes (RNN) son un tipo de modelo de aprendizaje automático que se utiliza para procesar secuencias de datos. Una de las variantes de las RNN es la Long Short-Term Memory (LSTM), que tiene una estructura de memoria que permite recordar información a lo largo de la secuencia y utilizarla para hacer predicciones o tomar decisiones. Las LSTM tienen una célula de memoria y tres puertas: de olvido, de entrada y de salida, que controlan el flujo de información y permiten a las LSTM manejar dependencias a largo plazo de manera eficiente.
