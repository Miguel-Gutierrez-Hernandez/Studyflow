1. Redes Neuronales

El Deep Learning es una subdisciplina del Machine Learning que se centra en la creación y el entrenamiento de redes neuronales artificiales profundas. Estas redes artificiales imitan el funcionamiento del cerebro humano para aprender y tomar decisiones de manera autónoma. El objetivo de las redes neuronales es capturar las características esenciales del cerebro y aplicarlas en entornos artificiales, a pesar de la complejidad de este último. Las redes neuronales artificiales tienen dos propiedades clave basadas en el cerebro: la neurona artificial o nodo, que recibe información de entrada y la transmite a otras neuronas, y el filtrado de información relevante, que permite transmitir solo la información más relevante. El Deep Learning ha ganado popularidad debido a sus impresionantes avances y resultados, demostrando superar las capacidades humanas en tareas complejas. Un ejemplo destacado es la clasificación de ImageNet, donde un estudio logró un error de prueba del 4,94%, superando por primera vez el rendimiento humano en esta tarea de reconocimiento visual. El Deep Learning ha sido utilizado en una variedad de aplicaciones, incluyendo el procesamiento de lenguaje natural, la predicción de series temporales y la traducción automática. En el contexto de esta asignatura, el Deep Learning se enfoca en la creación y el entrenamiento de redes neuronales para resolver problemas complejos, como el procesamiento secuencial de datos, que es el objetivo del uso de las redes Long Short-Term Memory (LSTM).
